# Why preserve intent?

Research and software projects begin with questions, problems, and hoped-for outcomes. HUMAN.md expresses a commitment to keeping that reasoning visible and traceable as the project develops, including when experiments or implementation change our understanding. There is no fixed structure: a note, questions, or links to existing research and decisions can give that thinking a home.

The initial purpose belongs to a human. An agent can help express an idea, test an assumption, or expose a tradeoff. It should ask when a proposed implementation changes the project's fundamental direction. AI can propose. Humans decide.

An optional Creator's note can explain the personal motivation behind that purpose. It belongs in the creator's own voice and can accompany any project type, with room for hopes, uncertainty, and questions as well as goals.

Using agents leaves people responsible for choosing what to delegate, providing direction, reviewing generated code before using it, and deciding how the resulting software is used. HUMAN.md provides a place to explain those choices; writing them down does not replace exercising that judgment.

Git can tell us when a function changed. The reasoning behind a new goal, a discarded hypothesis, or a revised definition of success often lives elsewhere. Git preserves revisions to HUMAN.md, while the explanations in it give those changes meaning. An optional Decision Log, revised reflection, or link to an experiment can explain what changed and why. Record meaningful shifts without documenting every task.

Thinking before coding can begin with an unanswered question. The next step may be a small experiment: write down what you want to learn, which assumption you are testing, and what evidence would help you decide what to do next. You can start without an exhaustive plan and revise the approach as you learn. Record proposed evaluations as plans and findings only when supported by evidence.

This is an evolving proposal, with no claim of proven effectiveness or established adoption. Markdown keeps it portable and readable. A few honest sentences can be enough to begin; the CLI simply provides a template.
